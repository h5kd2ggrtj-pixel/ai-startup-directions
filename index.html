面向产业资本的 10 条 AI 研究线索

以下是不同产业环节的观察名单，不构成买入建议；公司是否“低估”必须结合最新估值、订单、现金流和公告复核。

1｜国产 CPU / DCU

海光信息（688041）
逻辑：服务器 CPU、DCU 与国产算力生态，连接大模型训练、推理和政企信创。关注点：软件生态、客户结构、供货与估值。

2｜AI 加速器

寒武纪（688256）
逻辑：AI 芯片和加速卡的国产替代。关注点：产品迭代、算力卡商业化、生态适配和持续研发投入。

3｜内存接口芯片

澜起科技（688008）
逻辑：DDR5、服务器内存接口和 AI 服务器带来的高带宽需求。关注点：代际升级、客户验证和周期波动。

4｜存储芯片

兆易创新（603986）
逻辑：NOR Flash、SLC NAND、利基型 DRAM、MCU 与端侧 AI。关注点：存储周期、价格、汽车/工业客户和产品结构。

5｜服务器与智算中心

中科曙光（603019）
逻辑：服务器、算力集群、液冷和国产化数据中心。关注点：项目回款、算力利用率、客户集中度和资本开支。

6｜高速光模块

新易盛（300502）
逻辑：AI 数据中心内部互联带来的 400G/800G/更高速率光模块需求。关注点：海外客户、技术迭代、产能和价格竞争。

7｜工业视觉与边缘 AI

虹软科技（688088）
逻辑：计算机视觉算法向手机、汽车、IoT 和边缘设备渗透。关注点：算法授权、客户集中度、端侧 AI 变现。

8｜数据智能与行业大模型

拓尔思（300229）
逻辑：中文 NLP、政企数据和行业知识库，接近“数据+软件+智能体”模式。关注点：项目质量、应收账款、可复制收入。

9｜企业 AI 软件

金山办公（688111）
逻辑：办公入口、企业知识库和 AI 助手，属于大模型“挣钱”的应用层。关注点：AI 付费渗透、企业订阅、用户留存。

10｜网络安全与 AI 安全

奇安信（688561）
逻辑：模型安全、数据安全、身份与企业安全运营。关注点：安全预算、订单现金化、AI 安全新产品收入。

跨境与产业交易

另外三条适合产业资本研究的方向

Token 出海

不是单纯发行代币，而是研究稳定币结算、跨境收款、企业钱包、合规托管、链上风控和数字资产合规。先选一个国家走廊，验证牌照、银行通道和真实贸易流。

芯片与存储买卖

可以做“产业库存与供应链交易系统”：库存、交期、认证、价格、质保、回收和跨境合规一体化。比单纯倒卖更有壁垒，适合能源/资源整合型背景。

大模型公司股权投资

建立“模型层—算力层—数据层—行业应用层”四层筛选表。未上市公司重点看客户合同、毛利、推理成本、续费、创始团队和融资条款；A 股观察名单只作为产业映射。

模型商业化

开源模型：权重免费，服务收费

商业模式要与官方许可、客户数据边界和交付责任一起审查。

私有化部署

模型适配、性能调优、集群调度、行业微调、监控与升级。客户为数据隔离、业务连续性和交付责任付费。

云 + 模型套餐

把模型、服务器、网络、存储、运维和本地算力中心打包，收入来自建设费、算力费、订阅费与运维费。

企业级 API

按量、包月或包年收费，叠加专属额度、私有网络、微调、日志审计和 SLA。

商用授权

重点核对商业许可、规模门槛、收入分成、地域限制和模型衍生物条款；不能把“开源”直接等同于“无限制商用”。

数据状态：商业模式为行业研究框架；具体模型的价格、授权和性能必须以模型厂商当前官方页面或合同为准。

算力出海

从“Token”拆到可验证的产业链

供给端

西部数据中心、绿电、储能、网络、服务器、GPU/CPU、内存和存储。

服务端

模型 API、路由聚合、私有化部署、推理优化、容灾、多云和海外客户支持。

收入端

API 调用费、算力租赁、部署服务费、微调费、企业订阅、授权费和运维费。

风险端

出口管制、数据跨境、牌照、税务、芯片供应、汇率、模型许可和客户所在地监管。

研究提示：Token 是计量单位，不等同于可自由跨境交易的商品；任何“Token 出口”说法都必须单独核对监管定义。

投资研究流程

从趋势到观察名单

1｜官方趋势政策、财报、定价、许可、订单和监管文件。
2｜业务验证收入是否单列、客户是否真实、订单是否可追踪、现金流是否匹配。
3｜风险与估值核对估值、减持、解禁、诉讼、应收账款、供应链和商业化兑现。
