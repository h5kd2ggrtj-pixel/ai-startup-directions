一页读懂

执行摘要：先现金流，再产业协同，最后战略期权

这不是“押一个模型”的计划，而是把 AI 机会拆成可以验证、投资和持续跟踪的组合。

首选｜API 自动维护工具

推荐指数 93。启动成本低、验证周期短，可从 Stripe/GitHub 生态切入，用 PR 合并率和修复成功率证明价值。

第二｜小软件专属云

推荐指数 91。承接 AI 编程带来的长尾部署需求，核心看首次部署成功率、30 日留存与资源毛利。

第三｜AI 原生合规

推荐指数 90。监管需求明确，适合以 AI 资产清单、调用审计和敏感信息检测切入。

12 个月判断标准

至少形成 3 个付费试点、一个可重复套餐、一组真实使用数据，以及可解释的风险边界。

产业资本学习视角

三层结构：应用层 → 平台层 → 基础设施层

同一个 AI 机会，可以从“谁使用”与“谁提供底座”两个角度理解。

应用层｜解决具体问题

AI 私人老师、多人协作 AI、十亿级 AI 消费产品、银发 AI 服务、AI 原生合规系统。

平台层｜支撑应用运行

小软件专属云、现实世界操作系统、真人验证系统、API 自动维护工具。

基础设施层｜算力、数据与现实世界

国防科技、海上数据中心、加密货币基础设施、现实世界数据采集。

产业资本看点

优先看真实订单、资源协同、国产替代、现金流、牌照与产业链控制力，而非只看模型参数。

配置逻辑

投资组合建议：四个时间尺度

近期现金流｜0—12 个月

API 自动维护、AI 原生合规、小软件专属云。目标是快速获得付费试点和标准化套餐。

中期产业协同｜1—3 年

现实世界操作系统、现实世界数据采集、银发 AI。重点利用既有产业、渠道和场景资源。

长期战略期权｜3 年以上

海上数据中心、国防科技、真人验证。采用小额里程碑投资，避免过早重资产投入。

二级市场映射

芯片、存储、服务器、光模块、企业软件与网络安全，仅作为产业链观察名单，不替代估值和财务尽调。

投资委员会版本

最终建议：先投验证能力，再投规模

以下比例是项目筛选阶段的资金配置框架，不是证券收益预测；每一笔投入都必须绑定里程碑、数据室和退出条款。

A档｜立即验证｜建议占探索预算 45%

API 自动维护、AI 原生合规、小软件专属云。采用“小额首投 + 里程碑追加”，首笔只覆盖 3—6 个月验证期。放款条件：明确付费方、3 个试点、可复用报价单、数据与代码权属清晰。

B档｜产业协同｜建议占 30%

现实世界操作系统、现实数据采集、银发 AI。只有在能够提供场景、渠道或供应链资源时进入；否则容易变成重交付项目。重点核对项目毛利、回款周期和现场实施成本。

C档｜战略期权｜建议占 15%

真人验证、国产算力、存储与芯片交易系统。以可转换工具、联合实验室或订单融资优先，避免在标准、牌照和供应不确定时直接高估值股权投入。

D档｜研究储备｜建议占 10%

海上数据中心、国防科技、跨境数字资产基础设施。只做法规、资源和客户预研；没有牌照路径、锚定客户和工程测算前，不进入重资产建设。

统一否决项：没有真实客户；收入依赖关联交易；模型或数据权属不清；毛利由补贴支撑；回款超过 12 个月且无担保；核心业务需要尚未获得的牌照；以“保收益”方式销售算力或设备。

悲观情景

试点无法转年费、销售周期超过 9 个月、交付高度定制。处理：冻结扩招，只保留一个窄产品，累计现金投入不超过批准预算的 60%。

基准情景

3 个试点中至少 1 个转年度合同，新增客户获取可重复，毛利达到模型下限。处理：按月度经常性收入与续费率分两次追加。

乐观情景

渠道合作带来批量客户、交付标准化、净收入留存超过 110%。处理：优先扩产品与渠道，不急于增加低毛利定制项目。

执行工作台

90 天行动计划与投资闸门

第 1—30 天｜建立证据

完成 30 个访谈，其中付费决策人不少于 15 个；为前三方向分别形成客户画像、报价单、原型和 10 家目标客户名单；建立数据室目录和监管问题清单。

第 31—60 天｜获得承诺

每个优先方向至少获得 1 个付费试点或有金额、有期限的采购意向；完成云成本、交付成本和安全边界测算；候选公司完成创始人、客户和前员工交叉访谈。

第 61—90 天｜作出选择

只保留最多 2 个项目进入追加投资；形成投委会备忘录、条款清单、12 个月预算、最坏情景现金消耗和退出安排；其余项目进入季度观察池。

继续投资闸门

至少 3 个真实试点；至少 1 个已回款客户；产品使用频次可追踪；毛利达到模型下限；核心代码、模型和数据权属清晰。

暂停闸门

访谈认可但无人付款；每个客户都要重新开发；推理或交付成本随收入同比增长；创始团队无法给出现金使用计划。

退出闸门

连续两次未完成里程碑；出现重大合规、诚信或知识产权问题；关联交易支撑主要收入；需要持续融资才能维持负毛利业务。

交易工具箱

13 个方向不应使用同一种投资方式

控股孵化

适用：API 自动维护、小软件专属云、AI 私人老师。前提是能够组建产品团队并直接控制预算、客户和知识产权。

产业合资

适用：AI 原生合规、银发 AI、现实世界操作系统、现实数据采集。由产业方提供场景与渠道，技术方提供产品，条款中明确数据权属和最低采购。

少数股权／可转工具

适用：多人协作 AI、真人验证、消费产品和模型公司。用估值上限、折扣、信息权和里程碑降低早期估值不确定性。

订单融资／项目公司

适用：国防科技、芯片存储交易、数据采集和数据中心。资金必须与订单、设备和回款闭环绑定，避免用长期股权资金补短期库存。

另外三条产业资本主线

Token 出海、芯片存储交易、大模型股权投资

三条主线的共同原则：不做“概念套利”，只做牌照、订单、库存、现金流和股权条款能够穿透验证的交易。

1｜Token 出海：本质是跨境数字服务与合规结算

客户与产品

目标客户为跨境SaaS、游戏、电商、内容与开发者工具公司。产品不是发行代币，而是模型API路由、计量计费、跨境收款、企业钱包、稳定币结算选项、税务单据和链上风控。

推荐路径

先选一个国家或地区走廊；采用持牌合作方，不自建全部牌照；先做法币收款与账务，再评估稳定币结算；Token只作为模型计量单位，不将其包装成承诺收益资产。

90天证据

2家持牌合作方、10个真实跨境客户、100万元等值月度处理额意向、完整KYC/AML流程、资金路径图、税务与数据跨境法律意见。

投资与止损

优先合资或少数股权，按通道上线、真实交易额和净收入追加。若银行通道不稳定、客户资金混同、无法解释最终用户或依赖监管套利，立即停止。

2｜芯片与存储交易：从倒货升级为供应链操作系统

客户与产品

客户为服务器厂商、系统集成商、工业客户、渠道商和维修回收体系。产品覆盖SKU主数据、库存、价格、交期、认证、序列号、质保、回收、供应商评分和跨境合规。

商业模式

撮合佣金、交易毛利、供应链软件订阅、检测认证费、仓储物流费和订单融资服务费。软件与数据收入必须逐步提高，避免利润完全来自周期性价差。

90天证据

20家真实买方、10家合格供应商、3笔闭环订单、库存账实一致、坏货与退货率、回款周期、单笔毛利、出口分类和最终用户审查流程。

投资与止损

采用订单融资或项目公司；资金与订单、仓单、序列号和回款账户绑定。若无真实订单先囤货、库存无法穿透、货源权属不清或毛利依赖价格上涨，停止投入。

3｜大模型公司股权投资：买商业化与治理，不只买榜单

筛选范围

模型层、推理与算力层、数据与工具层、行业应用层。候选公司包括月之暗面、DeepSeek、阶跃星辰、百川、智谱、MiniMax等，但资本状态必须以最新投资者关系、公司和监管文件为准。

数据室核心

按产品拆分收入与毛利、付费用户、企业合同、推理成本、续费、客户集中、研发现金消耗、模型与训练数据权属、关联交易、股东名册、期权池和历史融资条款。

条款结构

优先少数股权或可转工具；关注估值上限、折扣、清算优先权、反稀释、信息权、董事观察员、下一轮优先认购和重大事项保护。不得用回购承诺掩盖经营风险。

停止条件

收入无法与补贴区分、模型成本不可解释、重大客户依赖、数据权属不清、创始人治理失衡、旧股东条款过度优先、估值仅由模型榜单支撑或退出路径不成立。

跨境与产业交易

另外三条适合产业资本研究的方向

Token 出海

不是单纯发行代币，而是研究稳定币结算、跨境收款、企业钱包、合规托管、链上风控和数字资产合规。先选一个国家走廊，验证牌照、银行通道和真实贸易流。

芯片与存储买卖

可以做“产业库存与供应链交易系统”：库存、交期、认证、价格、质保、回收和跨境合规一体化。比单纯倒卖更有壁垒，适合能源/资源整合型背景。

大模型公司股权投资

建立“模型层—算力层—数据层—行业应用层”四层筛选表。未上市公司重点看客户合同、毛利、推理成本、续费、创始团队和融资条款；A 股观察名单只作为产业映射。

模型商业化

开源模型：权重免费，服务收费

商业模式要与官方许可、客户数据边界和交付责任一起审查。

私有化部署

模型适配、性能调优、集群调度、行业微调、监控与升级。客户为数据隔离、业务连续性和交付责任付费。

云 + 模型套餐

把模型、服务器、网络、存储、运维和本地算力中心打包，收入来自建设费、算力费、订阅费与运维费。

企业级 API

按量、包月或包年收费，叠加专属额度、私有网络、微调、日志审计和 SLA。

商用授权

重点核对商业许可、规模门槛、收入分成、地域限制和模型衍生物条款；不能把“开源”直接等同于“无限制商用”。

数据状态：商业模式为行业研究框架；具体模型的价格、授权和性能必须以模型厂商当前官方页面或合同为准。

算力出海

从“Token”拆到可验证的产业链

供给端

西部数据中心、绿电、储能、网络、服务器、GPU/CPU、内存和存储。

服务端

模型 API、路由聚合、私有化部署、推理优化、容灾、多云和海外客户支持。

收入端

API 调用费、算力租赁、部署服务费、微调费、企业订阅、授权费和运维费。

风险端

出口管制、数据跨境、牌照、税务、芯片供应、汇率、模型许可和客户所在地监管。

研究提示：Token 是计量单位，不等同于可自由跨境交易的商品；任何“Token 出口”说法都必须单独核对监管定义。

投资研究流程

从趋势到观察名单

1｜官方趋势政策、财报、定价、许可、订单和监管文件。
